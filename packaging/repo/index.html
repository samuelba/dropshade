Dropshade packages

The apt and dnf repositories of Dropshade, a drop-down terminal for Linux.

Installing a .deb or .rpm from the latest release adds the repository for you, and your package manager keeps Dropshade up to date from then on. To add it without downloading a package first:

Debian 12+, Ubuntu 22.04+

sudo install -d -m 0755 /etc/apt/keyrings
sudo curl -fsSLo /etc/apt/keyrings/dropshade.asc https://samuelba.github.io/dropshade/dropshade.asc
sudo curl -fsSLo /etc/apt/sources.list.d/dropshade.sources https://samuelba.github.io/dropshade/deb/dropshade.sources
sudo apt update && sudo apt install dropshade

Fedora

sudo curl -fsSLo /etc/pki/rpm-gpg/RPM-GPG-KEY-dropshade https://samuelba.github.io/dropshade/dropshade.asc
sudo curl -fsSLo /etc/yum.repos.d/dropshade.repo https://samuelba.github.io/dropshade/rpm/dropshade.repo
sudo dnf install dropshade

The metadata is signed with the key in dropshade.asc. To stop updates from here, set Enabled: no in /etc/apt/sources.list.d/dropshade.sources or enabled=0 in /etc/yum.repos.d/dropshade.repo.
